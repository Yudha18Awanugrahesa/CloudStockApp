# Cloud Stock

Starter boilerplate untuk aplikasi SaaS manajemen stok & POS.

## Stack
- Next.js + TypeScript
- Tailwind CSS
- Supabase/PostgreSQL (siap diintegrasikan)
- Framer Motion
- Zod

## Tahap berikutnya di VS Code
1. `npm install`
2. Salin `.env.example` menjadi `.env.local`
3. Isi kredensial Supabase.
4. `npm run dev`
5. Buka `http://localhost:3000`

Catatan: paket ini adalah foundation/boilerplate, bukan aplikasi production lengkap. Core inventory logic, schema SQL, RLS, dan UI awal disediakan sebagai titik mulai.
